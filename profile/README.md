# Auxillo

**Managed hosting, diagnostic tools, and operational platforms - built by an architect, not a support department.**

Auxillo is independently operated by Jaundre van Staden, a systems architect based in Portimao, Portugal. Every hosting environment, every diagnostic tool, every line of infrastructure code is built, deployed, and maintained by one person. When you subscribe, you work directly with the architect who designed your environment. No support tiers. No ticket queues. No chatbots.

## What Auxillo provides

### Managed Hosting

WordPress hosting on isolated servers in Germany. Enterprise threat protection, global CDN speed coverage, daily encrypted backups, performance tuning - all handled by the architect. Servers in Germany, backups in Stockholm, Sweden. Your data never leaves Europe. Each environment is manually configured and secured from scratch, not provisioned from a template.

### Aux Tools

148+ automated diagnostic checks across 14 categories. Enter a domain, run a scan, get a structured report. Covers DNS records (A, AAAA, MX, CNAME, TXT, SOA, NS), email security (SPF, DKIM, DMARC, BIMI, MTA-STS), SSL/TLS analysis, security headers, network performance, blacklist monitoring, breach detection, DNSSEC validation, technology stack detection, and more. Includes automated monitors with email/Slack/webhook alerts, scheduled reports, bulk scanning, and API access.

### Aux Command

A Linux remote-operations workstation for technical operators who need one controlled place to open local shells, SSH sessions, SFTP browsers, tunnels, serial consoles, and remote desktop launchers. Uses native OpenSSH for terminal sessions. Built with Electron sandbox, context isolation, and security-first credential handling. Available as AppImage, .deb, and .rpm packages.

### AMI Core

The AI assistant built into the Auxillo platform. Helps navigate the dashboard, recommends the right diagnostic tool for a given problem, explains scan results in plain language, and remembers context across conversations. Runs under a strict safety framework - it never accesses external systems without permission and never shares your data. Operates on EU infrastructure.

### Aux Domain

A free domain search tool that checks availability and compares registration prices across 200+ registrars worldwide. Live price comparison from 9 integrated registrar APIs (Porkbun, Spaceship, Namecheap, GoDaddy, Cloudflare, NameSilo, Dynadot, Gandi, Name.com). Keyword search across 100+ TLDs. RDAP availability verification. No account needed. Completely free.

### Aux Mail

Privacy-first email client, CRM, and campaign platform in one subscription. End-to-end encryption with PGP/MIME RSA-4096 keys. Built-in CRM with deals, pipelines, and automation. Drag-and-drop campaign designer with A/B testing, dynamic segments, and scheduled sends. Deliverability dashboard with SPF/DKIM/DMARC monitoring and live inbox placement tests. EU data residency. Replaces Mailchimp, HubSpot, and ProtonMail under one bill.

### Aux SEO

Full SEO platform with 10 modules in one subscription: rank tracking, keyword research, competitor intelligence, site crawler, content analysis, backlink analysis, YouTube SEO, social monitoring, e-commerce SEO, and app store optimization. Automated branded reports. Real-time alerts for rank drops, audit failures, SSL expiry, and blacklist events.

## How Auxillo is different

Auxillo is not a company with departments and tiers. Every customer works directly with the same person who builds and manages the infrastructure. There is no sales team. There is no ticket queue. When something needs attention, the message goes to the architect.

**Direct architect access** - Every request goes straight to the systems architect. One person, full accountability.

**EU data only** - Servers in Germany. Backups in Stockholm. Your data never leaves Europe.

**Zero tracking** - No pixels, no profiling, no behavioral analytics. Full GDPR compliance by design.

**Verified results** - Every diagnostic queries live authoritative sources. Real-time, never cached.

## Philosophy

Your infrastructure should be an asset, not a liability. Automation has its place. Critical decisions do not.

All Auxillo tools are built on standard, open-source architectures with no vendor lock-in. If you ever need to migrate away, your infrastructure moves seamlessly.
