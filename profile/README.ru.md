# Auxillo

**Настольные инструменты для инфраструктурных операций - созданы системным архитектором, с открытым исходным кодом.**

Auxillo независимо управляется Яундре ван Стаденом, системным архитектором из Portimao, Португалия. Эта организация GitHub публикует бесплатные open-source настольные инструменты для операторов реальных систем.

Размещаемые продукты Auxillo (диагностика, управляемый хостинг, домены, почта) отдельны и находятся на [auxillo.tech](https://auxillo.tech). Они не входят в эти репозитории.

## Что мы публикуем здесь

| Продукт | Описание |
|---|---|
| **[Aux Command](https://github.com/Auxillo-Tech/Aux-Command)** | Linux-рабочая станция для удалённых операций: SSH, SFTP, туннели, serial, Mosh, Telnet, RDP, VNC и локальные оболочки в одной security-first консоли. Пакеты: AppImage, `.deb`, `.rpm`. |
| **[Aux Proton Drive Bridge](https://github.com/Auxillo-Tech/Aux-Proton-Drive-Bridge)** | Linux-десктопный мост для Proton Drive - синхронизация, монтирование, конфликты и интеграция с файловым менеджером через официальный CLI Proton. Пакеты: AppImage, `.deb`, `.rpm`. |

## Статус

- **Aux Command** - активная линия релизов Linux x86_64 с подписанными пакетами
- **Aux Proton Drive Bridge** - активная линия релизов Linux desktop с подписанными пакетами
- **Поддержка** - добровольные чаевые через [Buy Me a Coffee](https://www.buymeacoffee.com/auxillo)

## Подход

- Безопасные настройки по умолчанию и чёткие границы доверия
- Предпочитать зрелые нативные Linux-инструменты вместо переизобретения протоколов в Electron
- Без платных стен на этих open-source десктопных инструментах
- Проверяемая упаковка, которую операторы могут установить сами
