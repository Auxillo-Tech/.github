# Auxillo

**Десктопные инструменты для управления инфраструктурой – созданы архитектором, с открытым исходным кодом.**

Auxillo независимо управляется Яундре ван Стаденом, системным архитектором из Португалии, Портиман. Эта организация размещает десктопные инструменты с открытым исходным кодом. Полная платформа Auxillo – управляемый хостинг, диагностические инструменты, электронная почта и домены – находится на auxillo.tech.

## Репозитории

### Aux Command

Рабочая станция Linux для удалённых операций, предназначенная для технических специалистов, которым нужно единое контролируемое место для открытия локальных оболочек, SSH-сессий, SFTP-браузеров, туннелей, последовательных консолей, Mosh, Telnet, RDP, VNC и запуска удалённых рабочих столов. Использует нативный OpenSSH для терминальных сессий. Создана с использованием песочницы Electron, изоляции контекста и безопасной обработки учётных данных. Доступна в форматах AppImage, .deb и .rpm.

### Aux Proton Drive Bridge

Десктопный мост для Linux, который синхронизирует, монтирует и управляет томами Proton Drive с двусторонней поддержкой. Обрабатывает разрешение конфликтов, зашифрованный локальный кэш, интеграцию с файловым менеджером и опциональное монтирование FUSE. Использует официальный CLI Proton для аутентификации – ваш пароль никогда не обрабатывается мостом.

## Философия

Ваша инфраструктура должна быть активом, а не обязательством. У автоматизации есть своё место. У критических решений его нет.

Оба инструмента построены на стандартных архитектурах с открытым исходным кодом, без привязки к вендору и без платных функций.
