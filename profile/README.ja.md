# Auxillo

**インフラ運用向けデスクトップツール - システムアーキテクトが構築、オープンソース。**

Auxillo は、ポルトガルの Portimao を拠点とするシステムアーキテクト Jaundre van Staden が独立して運営しています。この GitHub 組織は、実運用のオペレーター向けに無料のオープンソース デスクトップツールを公開します。

ホスト型の Auxillo 製品（診断、マネージドホスティング、ドメイン、メール）は別系統で [auxillo.tech](https://auxillo.tech) にあります。これらのリポジトリには含まれません。

## ここで公開するもの

| 製品 | 説明 |
|---|---|
| **[Aux Command](https://github.com/Auxillo-Tech/Aux-Command)** | Linux リモート運用ワークステーション：SSH、SFTP、トンネル、シリアル、Mosh、Telnet、RDP、VNC、ローカルシェルをセキュリティ優先のコンソールに統合。パッケージ：AppImage、`.deb`、`.rpm`。 |
| **[Aux Proton Drive Bridge](https://github.com/Auxillo-Tech/Aux-Proton-Drive-Bridge)** | Proton Drive 向け Linux デスクトップブリッジ - 公式 Proton CLI による同期、マウント、競合処理、ファイルマネージャ連携。パッケージ：AppImage、`.deb`、`.rpm`。 |

## ステータス

- **Aux Command** - 署名付きパッケージのアクティブな Linux x86_64 リリースライン
- **Aux Proton Drive Bridge** - 署名付きパッケージのアクティブな Linux デスクトップ リリースライン
- **サポート** - [Buy Me a Coffee](https://www.buymeacoffee.com/auxillo) による任意の支援

## 方針

- セキュリティ優先の既定値と明確な信頼境界
- Electron 内でプロトコルを再実装するより、成熟したネイティブ Linux ツールを優先
- これらのオープンソース デスクトップツールに有料機能の壁はない
- オペレーター自身が検証・インストールできるパッケージ
