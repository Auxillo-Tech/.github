# Auxillo

**オペレーターグレードのインフラストラクチャ、自動化、およびAI支援診断。**

Auxillo は、実際のシステムを運用する人々——創業者、エンジニア、セキュリティオペレーター、インフラ管理者——のためにツールを構築しています。スピードを求めつつも、制御を手放したくない人々のためのツールです。

私たちは、問題なく動いているときは邪魔をせず、問題が起きたときには明晰さをもたらすツールこそが最良だと信じています。

## プロダクト

| プロダクト | 説明 |
|---|---|
| **Aux Command** | リモート運用ワークステーション——分散シェル、診断パネル、フリート全体での実行、組込みVNC/RDP、および多数のマシンを管理するオペレーター向けエージェントオーケストレーション |
| **Aux Proton Drive Bridge** | Proton Drive ボリュームの同期、マウント、管理を行うデスクトップブリッジ。双方向同期、競合処理、暗号化ローカルキャッシュ、ファイルマネージャ統合を提供 |


## 理念

- **ローカルファースト。** セルフホスティング、プライバシー重視の運用を前提に設計しています。クラウドサービスはオプションであり、決して必須ではありません。
- **オペレータースピード。** 私たちが構築するすべてのツールは、「これは復旧までの時間を短縮できるか？」という問いから始まります。
- **セキュリティファースト。** 認証、暗号化、アクセス境界は後付けではなく、基盤です。
- **オープンソース。** すべてのツールは公開されており無料です。エンタープライズ版も有料プランも機能制限もありません。

## ステータス

Auxillo は現在プロダクトラインを積極的に開発中です。ほとんどのシステムは、公開リリース前に十分に堅牢化され、本番環境で使用されています。

- **[Aux Command](https://github.com/Auxillo-Tech/Aux-Command)** — 積極的に開発中（堅牢化の間はプライベート）
- **[Aux Proton Drive Bridge](https://github.com/Auxillo-Tech/Aux-Proton-Drive-Bridge)** — 初期リリース（堅牢化の間はプライベート）
