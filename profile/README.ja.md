# Auxillo

**インフラ運用のためのデスクトップツール – アーキテクトが構築、オープンソース。**

Auxillo は、ポルトガルのポルティマンを拠点とするシステムアーキテクト Jaundre van Staden が独立して運営しています。この組織はオープンソースのデスクトップツールをホストしています。Auxillo の全プラットフォーム（マネージドホスティング、診断ツール、メール、SEO、ドメイン）は auxillo.tech にあります。

## リポジトリ

### Aux Command

ローカルシェル、SSH セッション、SFTP ブラウザ、トンネル、シリアルコンソール、Mosh、Telnet、RDP、VNC、リモートデスクトップランチャーを一元的に管理できる、技術オペレーター向けの Linux リモート操作用ワークステーション。端末セッションにはネイティブ OpenSSH を使用。Electron サンドボックス、コンテキスト分離、セキュリティ優先の認証情報管理で構築。AppImage、.deb、.rpm 形式で利用可能。

### Aux Proton Drive Bridge

Proton Drive ボリュームを双方向で同期、マウント、管理する Linux 向けデスクトップブリッジ。競合解決、暗号化ローカルキャッシュ、ファイルマネージャー統合、オプションの FUSE マウントに対応。認証には Proton 公式 CLI を使用 – パスワードがブリッジによって処理されることはありません。

## 哲学

あなたのインフラは資産であるべきで、負債であってはなりません。自動化には適切な場面があります。重要な判断には適切ではありません。

両ツールとも、標準的なオープンソースアーキテクチャに基づいて構築されており、ベンダーロックインや有料機能はありません。
