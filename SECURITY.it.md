# Politica di Sicurezza

Auxillo prende la sicurezza molto seriamente.

Se ritieni di aver trovato una vulnerabilità in un sistema o prodotto Auxillo, segnalala tramite il canale di contatto indicato di seguito.

## Segnalazione

- **Sito web:** [auxillo.tech](https://auxillo.tech)

Includi, per favore:

- Sistema, repository o URL interessato
- Riepilogo e tipo di vulnerabilità
- Passaggi per riprodurla
- Impatto potenziale
- Prove a supporto (log, screenshot, esempi di richiesta/risposta)

## Ambito

Solo i sistemi e i repository di proprietà e gestiti da Auxillo rientrano nell'ambito. Le dipendenze di terze parti sono escluse.

Sono vietati:
- Test distruttivi o denial-of-service
- Attacchi alle credenziali, tentativi di password o forza bruta
- Ingegneria sociale di qualsiasi tipo
- Attacchi fisici o tentativi di accesso alle strutture
- Test contro sistemi o servizi di terze parti

## Risposta

Le segnalazioni valide vengono esaminate, prioritizzate e riconosciute. La gravità viene valutata in base a sfruttabilità, raggiungibilità, risorse interessate, controlli esistenti e impatto aziendale.
